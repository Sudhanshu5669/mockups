# NGO demo imagery

These 32 WebP assets were generated for the four fictional NGO website concepts. People and scenes are illustrative, not photographs of actual beneficiaries, staff, or field work. Each mockup includes this disclosure.

The project uses relative local paths, descriptive alt text, cover crops in the existing image frames, and lazy loading for secondary images. Hero and mobile hero images load eagerly. The portfolio preview reuses the corresponding hero assets.

`../asset-manifest.json` records the generation prompts and local filenames. Replace these assets with consented NGO photographs before using the concepts as live organization websites.
